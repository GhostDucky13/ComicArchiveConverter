COMIC ARCHIVE CONVERTER {VERSION}
=================================

Turns folders of comic/manga pages into CBZ files, and CBZ / CBR / CB7 files
back into folders of images.


HOW TO START
------------
Double-click ComicArchiveConverter.exe

Nothing needs to be installed.
This build: {BUILD}

Keep all the files in this folder together:
the .exe needs the .dll files next to it.

If Windows shows "Windows protected your PC", click "More info" and then
"Run anyway". This appears because the program isn't code-signed.


HOW TO USE
----------
1. Drag comic folders or CBZ / CBR / CB7 files into the window.
2. Choose how chapter folders are packed:
     - All chapters in one CBZ, or
     - One CBZ per chapter
3. Press Convert.

Everything else (where to save, what happens to existing files, and so on)
is on the Settings page.

Supported images:   JPG, PNG, WebP, GIF, BMP, AVIF
Supported archives: CBZ/ZIP, CBR/RAR, CB7/7Z, CBT/TAR

Shortcuts: Ctrl+V paste copied files, Delete remove, F5 preview,
           Ctrl+Enter convert. Double-click a finished row to see its result.


SAFETY
------
- Your original folders and files are never changed or deleted.
- Every new CBZ is checked image by image before it gets its real name.
- Only convert comics you have the right to copy.


UNINSTALL
---------
Delete this folder. Settings are kept in
%AppData%\ComicArchiveConverter - delete that folder too to remove everything.


More information, source code and updates:
